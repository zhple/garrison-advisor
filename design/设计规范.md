# 卫戍协议·规程 阵容顾问：设计规范

版本：第一期（2026-11-17，Asia/Shanghai）  
适用：静态网页，移动优先；默认显示原创简化图标，可选读取用户本地头像目录。

## 1. 原则

- 好看、好懂：先告诉玩家「现在激活了没、下一步抓谁」，再展示完整配方。
- 不用官方立绘/头像，不外链 PRTS 图。默认用本目录原创简化图标；若用户在本地目录放入同名文件，再替换显示。工具不附带、不分发官方图。
- 文件名、页面用词一律用 PRTS 正式名。已核对：是「折桠」不是「折娅」，是「奥尔佳」不是「奥尔加」。

## 2. 布局

移动端（< 768px）单列，自上而下三块；桌面端（≥ 900px）上栏通栏，中右分栏。

1. **顶部：核心盟约选择**  
   十个核心盟约做成可换行的选择条（chip）。当前选中项放大描边，并用该盟约强调色。

2. **中部：推荐路线 + 已有干员**  
   - 左/上：前、中、后期抓取时间线，每段列出优先干员和附加盟约。  
   - 右/下：可勾选的干员清单。一行一名干员。  
   桌面端两列并排；手机上先路线、再清单。

3. **底部：激活状态 / 还差谁**  
   手机上吸底（为底部安全区留出 padding）。写清：  
   - 按「已勾选拥有」估算，6 人强化需在场；  
   - 奥术 2 人激活、3 人才强化（2 奥术不会触发减抗）；  
   - 勾选调和（魔王）后，核心盟约激活人数按 +1 计算。  
   主句只要一句：「乌萨斯已激活（3/3），下一步优先补冻河 / 奥术」。

页脚：赛季「规程·序列Ⅰ」、资料来源与日期、非官方声明、本地头像用法（指向 README）。

## 3. 字体与字号

字体栈：`"Noto Sans SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页面标题 | 22px / 28px | 600 |
| 区块标题 | 17px / 24px | 600 |
| 正文、干员名 | 16px / 24px | 400；干员名 600 |
| 标签（等阶、盟约） | 13px / 18px | 600 |
| 来源、脚注 | 13px / 18px | 400 |

必要信息不小于 13px。干员名不截断。勾选行最小高度 48px，以适配触控和放大字号。

## 5. 间距与圆角

基准 4px。页面左右边距手机 16px、桌面 24px；卡片内边距 16px；卡片间距 12px；chip 间距 8px；图标与名字间距 8px。

圆角：卡片 12px，chip 20px，等阶标签 6px，图标圆形。

触控：盟约 chip、勾选行、吸底「下一步」热区不小于 44×44px（推荐 48px）。勾选框视觉 20px，热区铺满整行。

## 6. 组件

- **干员行**：`[勾选热区] [40px 圆形图标] [正式名（链到 PRTS 该干员页）] [等阶标签] [盟约小标签]`。名字是唯一外链，只打开百科页面，不拉图。
- **时间线**：竖线 + 前/中/后期节点；每名干员同样用 32–40px 图标，可点即勾选同步到清单。
- **状态卡**：环形或条形进度，例如「乌萨斯 2/3」「奥术 2/2 已激活 · 强化 2/3 未达成」。调和生效时在核心进度旁标注「+1 调和」。
- **下一步条**：`accent` 底、深色字（`#12141A`，保证对比），一行人话 + 相关图标。

## 7. 图标与本地头像

资产目录（相对站点根）：

- 默认简化图标：`assets/icons/{正式名}.png`
- 本地覆盖（不入库、不随工具分发）：`local-avatars/{正式名}.png`  
  用户把游戏头像放进该目录后，同名干员改显示本地图；没有文件则继续用简化图标。README 由开发写清用法。

技术规格：

- 画布 128×128 PNG，圆形内容，圆外透明。页面按 40px 显示（桌面列表可用 48px）。
- 风格：原创扁平几何图标，2–4 色，一个辨识特征（发色块、角、冰晶、火焰等），不是立绘缩略图，不描摹官方图。
- 缺文件时的回退：盟约强调色圆底 + 名字首字，16px/600，`#F2F4F8`。
- 本地图同样裁成圆，`object-fit: cover`。

第一批交付（乌萨斯优先抓及相关）：折桠、烈夏、乌啾、真理、维伊、卡达、霍尔海雅、波登可、青枳、冻河、阿米娅、怒潮凛冬、塔露拉、魔王、奥尔佳。赫拉格可后补。其余九个核心盟约的图标随配方名单补齐。
