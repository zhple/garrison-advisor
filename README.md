# 卫戍协议·阵容顾问

非官方查询页。选定「卫戍协议·规程·序列Ⅰ」的核心盟约后，查看官方效果、社区推荐抓取路线（若有），并勾选这把已拿到的干员，估算盟约是否激活、还差谁。

本工具与鹰角网络无关，不能写成官方产品。数值以 [PRTS 盟约记录](https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录) 为准。社区推荐单独标注来源与日期。

## 赛季

**规程·序列Ⅰ**（2026-11-08 起，Asia/Shanghai）。

盟约数值、干员名单、等阶、特质和装备会随赛季或热更新调整。换赛季必须更新 `data/garrison-data.json`，再运行下面的生成命令，不要把旧路线写死在页面里。尤其不要沿用 2026 年 3 月「盟约 / 盟约下半」资料。

## 如何本地打开

任选一种即可：

1. **直接双击 `index.html`**（`file://`）。页面通过 `js/data.js` 同步加载数据，不依赖 `fetch`，避免浏览器拦截本地 JSON。
2. 在本目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/`。查完即可停止服务。

改数据时：先编辑 `data/garrison-data.json`，再生成同步包：

```bash
node js/build-data.js
```

界面只读这份 JSON / 生成后的 `js/data.js`。完备度（完整 / 单源，待补充 / 仅官方池）按文件里的 `completeness` 字段显示，不在代码里写死。

## 数据随版本变化

- 权威数据：`data/garrison-data.json`（文档维护）。
- `season` 为「规程·序列Ⅰ」，整理日期见 JSON 的 `updated`。
- 干员显示名只用 `officialName`。社区笔误（如折娅、奥尔加、M3茬甲）只出现在 `alias`，不会画到界面上。
- 装备（如 **M3茧甲**）在巧物 / 装备分组，不进干员表。魔王是调和干员，可在巧物区勾选。
- 炎配方若带「m3 二技能」这类未确认条目，页面标「待确认」，**不坐实为装备 M3茧甲，也不坐实为干员 Mon3tr**。
- 没有抓取表的核心盟约会写明「本期抓取顺序待补充」，仍可勾选官方池并计算激活，不会编造前中后期。
- 维多利亚按 `covenantId` + `routeId` 分条展示，两条路线不合成一套板面。

## 非官方声明

这是玩家自己用的静态页，不是明日方舟或卫戍协议的官方工具。官方效果摘自 PRTS，社区路线仅供参考。

## 官方图与本地头像

工具**不附带、不分发**官方立绘或头像，也不外链 PRTS 图鉴图。默认使用 `assets/icons/{正式名}.png` 的原创简化图标；没有图标时，用盟约强调色圆底加名字首字。

若只在自己电脑上看头像：把游戏内头像自行放入：

```text
local-avatars/正式名.png
```

例如 `local-avatars/折桠.png`、`local-avatars/乌啾.png`。有同名文件时优先显示本地图（圆形裁切），没有则回退简化图标。该目录不入库官方图。

```text

```

## 计算测试如何跑

需要已安装 Node.js。在本目录执行：

```bash
node js/calc.test.js
```

验收包括：折桠 + 烈夏未激活还差 1；再勾乌啾已激活并提示补奥术 / 迅捷 / 冻河；折桠 + 烈夏 + 魔王因调和提前激活；两奥术不得提示已减抗；六名乌萨斯须写明强化需在场。另覆盖跨核心计数、独行恰好 1 人、绝技按精锐人数计算。

改 `data/garrison-data.json` 后请先 `node js/build-data.js`，再跑测试。
